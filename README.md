# CodeAlpha Network Packet Analyzer

## Installation

To install the CodeAlpha Network Packet Analyzer, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Urehofhope/CodeAlpha_NetworkPacketAnalyzer.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CodeAlpha_NetworkPacketAnalyzer
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage Example

To use the CodeAlpha Network Packet Analyzer, run the following command:
```bash
node index.js
```

### Example Command:
```bash
node index.js --file somePacketFile.pcap
```

## Features
- **Real-time packet analysis:** Monitor the network traffic in real time.
- **File support:** Analyze PCAP files and extract meaningful data.
- **User-friendly GUI:** Provides a simplistic and elegant graphical user interface for interaction.
- **Multi-platform support:** Works on Windows, macOS, and Linux.
